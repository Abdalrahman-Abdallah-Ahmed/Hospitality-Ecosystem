## Route audit (T039)

Going through the write routes in `routes/api.php`, the unaudited hotel records a session can write beyond the five in FR-019b are import previews, the import column mapping and the `ReservationImport` row (a finished import records its summary event as the uploader). `VoucherEmailRequest` already has a named event on its reservation. Conversation rows are bookkeeping (`EventLogger::NOT_HOTEL_DATA`). `User` and `WhatsAppDevice` can't be written by a session. The other creates found run in jobs or on routes a session can't reach. The search covered `create`, `updateOrCreate`, `firstOrCreate`, `upsert` and `insert` calls in controllers, services and support classes, so a write made another way could be missed.
